# POS Simulator ECR WebSocket

A WebSocket-based Electronic Cash Register (ECR) simulator. Built using [Wails v2](https://wails.io/), providing a lightweight Go backend and a modern React frontend.

## 🛠️ Tech Stack

- **Backend:** Go
- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, Lucide React (Icons)
- **Framework:** Wails v2

## 🚀 Development Quick Start

Ensure you have Go, Node.js, and the Wails CLI installed globally (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`).

1. **Clone the repository:**

   ```bash
   git clone https://github.com/AndreSuryana/pos-simulator-ecr-ws.git
   cd pos-simulator-ecr-ws
   ```

2. **Run the development server:**

   ```bash
   wails dev
   ```

   _This starts the Go backend and the Vite frontend with hot-module reloading (HMR) enabled. Any changes to Go or React files will recompile automatically._

3. **Manual Build (Local):**

   ```bash
   wails build -clean -m -platform windows/amd64
   ```

   _The compiled `.exe` will be generated in the `build/bin/` directory._

## 📦 Release Workflow

This project uses a PR Release Pipeline via GitHub Actions. You do not need to manually create Git tags.

To publish a new release:

1. Open `wails.json` and bump the `"productVersion"` (e.g., `"2.0.1"`).
2. Push your changes to a new branch and open a **Pull Request** to main.
3. _(Optional)_ Download the `.zip` artifact generated by the PR checks to test the build.
4. Click **Squash and Merge**.

Upon merging, GitHub Actions will automatically:

- Detect the version from `wails.json`.
- Compile the Windows `.exe`.
- Package it into a `.zip` file.
- Generate a Git tag (e.g., `v2.0.1`).
- Publish the official GitHub Release with the attached download.
